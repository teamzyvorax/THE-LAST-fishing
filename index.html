02

RED FLAGS

Use these checks whenever a message pushes you toward a link.

01

Check the domain

Look for misspellings, strange subdomains, or domains that do not belong to the claimed service.

02

Urgency is a signal

Threats like “act now” or “your account will close” are common social-engineering tactics.

03

Verify independently

Open the official app or type the known website yourself instead of trusting the message link.

04

Never enter secrets

Never submit passwords, OTPs, recovery codes, or payment details to an unverified page.

SAFE BY DESIGN

TRAIN. VERIFY. PROTECT.

This project is intentionally built as an awareness simulator. It does not imitate a real service for credential capture, does not store submissions, and does not create deceptive login pages.
