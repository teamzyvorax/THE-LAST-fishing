# THE LAST — Fishing Safety Lab

A premium, responsive **phishing-awareness simulator**.

## Safety boundary
This project is intentionally educational. It does **not** collect passwords, OTPs, tokens, payment details, or other credentials, and it does not create deceptive real-service login pages.

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Files
- `index.html` — landing page and simulator
- `style.css` — responsive UI
- `script.js` — safe simulation interaction
